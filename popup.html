OpenModHeader Filter Guide

Choose which request URLs receive your header modifications.

Exact Host

Enter a host to match only that host.

google.com

Matches https://google.com/search.

Does not match www.google.com, sub.google.com, or notgoogle.com.

Wildcard Host

Use * inside a host pattern. A leading *. also includes the base host.

*.google.*

Matches www.google.com, sub.google.com, and sub.google.dev.

Local Or URL

Local hosts, IPs, and full URLs are understood automatically.

localhost 127.0.0.1 https://order.basalam.com

Important behavior

  • Multiple enabled filters use OR logic: matching any one filter is enough.
  • A disabled filter is ignored.
  • With no filters, modifications apply to all URLs.
  • Only the currently active profile is applied.
  • Pause disables all modifications.
